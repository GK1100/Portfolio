I’ve also co-authored an IEEE conference paper on machine learning for antimicrobial resistance data.

This repository contains my interactive portfolio, built with React, TypeScript, and Vite.

## Run with Docker

Build and run the production site on a machine with Docker installed:

```bash
docker build -t gaurav-portfolio .
docker run --rm -p 8080:8080 gaurav-portfolio
```

Open [http://localhost:8080](http://localhost:8080) to view the portfolio. The Docker image builds the app with Node.js and serves the static site with unprivileged Nginx.
